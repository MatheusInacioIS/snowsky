# SNOW SKY — Site de apresentação

Landing page responsiva do jogo independente SNOW SKY, construída com **HTML5, CSS3 e JavaScript puro**.

## Como executar

Abra `index.html` em qualquer navegador moderno. Não é necessário instalar nada nem iniciar servidor.

## Estrutura

- `index.html` — seções semânticas, conteúdo e links.
- `styles.css` — identidade visual, layout, responsividade e animações.
- `script.js` — menu mobile e entradas suaves com IntersectionObserver.
- `assets/maya.png` — sprite fornecido pela equipe.
- `assets/luma.png` — sprite fornecido pela equipe.
- `assets/tela-original.png` — referência visual fornecida.
- `assets/capa-snow-sky.png` — arte de capa criada para esta versão.

## Ajustes rápidos

- Paleta: variáveis no início de `styles.css`.
- Link para jogar: `https://snow-skygame2.vercel.app/` em `index.html`.
- Sinopse: seção `#historia` em `index.html`, mantida literalmente como solicitada, inclusive a palavra “brigar”.
- Sprite animado: seletores `.hover-animation`, `.hoverboard` e `@keyframes hover-flight` em `styles.css`.

Os arquivos de imagens são locais. Apenas a fonte Google Fonts requer conexão; fontes alternativas locais estão configuradas.
